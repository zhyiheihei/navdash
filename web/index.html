设为浏览器主页

出于安全，浏览器不允许网页直接修改主页，请按下方引导手动设置：

  1. Chrome / Edge：设置 → 外观 → 「显示主页按钮」→ 填入下方地址；「启动时」→ 打开特定网页。
  2. Firefox：设置 → 主页 → 自定义网址 → 填入下方地址。
  3. Safari：设置 → 通用 → 主页 → 填入下方地址。新标签页也可指向「个人收藏」。
